# Familiar Faces

A World of Warcraft Forever addon that remembers who you played with: when you grouped, in which zones and dungeons, and which quests you did together.

## Install
Copy the `FamiliarFaces` folder into `World of Warcraft\_forever_\Interface\AddOns\` and restart the game.

## Use
- `/ff` or `/faces` opens the window.
- Player tooltips show when you last played with someone.
- Right-click entries to rate players or add notes.
